# NATURAL-LANGUAGE-PROCESSING-INCORPORATING-USE-OF-BIG-DATA-PROCESSES-AND-TIME-SERIES-ANALYSIS
The rapid growth of user-generated content and large-scale textual datasets has significantly increased the importance of Natural Language Processing (NLP) within the domain of big data analytics. This project investigated the integration of big data technologies, Natural Language Processing methodologies, and time series analysis techniques to develop a predictive framework for restaurant rating analysis using customer review data from Madrid and Paris. The study specifically focused on restaurant reviews from the year 2019 to provide insights into consumer sentiment and rating patterns during the pre-pandemic period.

The project leveraged large-scale datasets obtained primarily from Kaggle and supplementary online data sources. To effectively manage the volume, velocity, and variety of the collected data, the Hadoop Distributed File System (HDFS) was employed as the primary storage infrastructure. HDFS provided a scalable and fault-tolerant environment capable of efficiently storing extensive structured and unstructured textual datasets. Data processing and analysis were subsequently conducted within a Jupyter Notebook environment using PySpark, which facilitated distributed computing and high-performance processing of large-scale data.

As part of the study, different database distribution systems were evaluated to determine their suitability for handling restaurant review datasets. The performance of MongoDB and MySQL was assessed using the Yahoo! Cloud Serving Benchmark (YCSB), an open-source benchmarking framework designed for evaluating NoSQL and relational database management systems. MongoDB, a document-oriented NoSQL database, demonstrated considerable advantages in managing unstructured and semi-structured textual data due to its scalability, schema flexibility, and capacity to accommodate missing values and duplicate records commonly found in restaurant reviews. Conversely, MySQL exhibited strong transactional consistency and adherence to ACID properties but was comparatively less adaptable for processing highly diverse and unstructured review data.

To support efficient large-scale data processing, the project adopted the Lambda Architecture framework, which combines batch processing and real-time data streaming to deliver scalable and fault-tolerant analytical capabilities. This architecture enabled both historical and near real-time analysis of restaurant reviews, thereby supporting dynamic insight generation and predictive modelling. Furthermore, the study explored the role of distributed NoSQL systems such as HBase, Apache Cassandra, Apache Druid, and Apache Flink in addressing various big data processing requirements and improving system scalability and performance.

Time series analysis techniques were incorporated to identify trends and temporal patterns in restaurant ratings and customer sentiment over the selected period. The integration of NLP methodologies with big data infrastructures facilitated the extraction of meaningful insights from large volumes of textual review data, contributing to the development of predictive models for restaurant ratings in Madrid and Paris.

The findings highlight the effectiveness of integrating HDFS, PySpark, Lambda Architecture, and NoSQL databases for scalable text analytics and predictive modelling. This research contributes to the broader field of data-driven decision-making by providing valuable insights into consumer behaviour, restaurant performance, and the application of advanced analytical techniques within hospitality and urban data environments.
